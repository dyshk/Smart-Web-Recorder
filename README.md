# 智能听力录音机

这是一个浏览器扩展，用来录制当前网页标签页的声音，并把音频片段保存为 WAV / WEBM / MP3 文件。

## 功能特性

- **标签页音频录制**：一键捕获当前网页播放的声音
- **固定窗口置顶**：点击固定按钮，录音窗口持续保持在浏览器最前面
- **优化波形可视化**：渐变色波形 + 4 倍子峰值采样，频率细节丰富，面积更紧凑
- **拖动选区**：在波形上拖动选择听力片段，支持整体移动
- **试听片段**：选中后可试听确认再保存
- **多格式导出**：支持 WAV / WEBM / MP3（取决于浏览器编码支持）
- **跨浏览器兼容**：支持 Chrome、Edge、Firefox 主流浏览器

## 兼容浏览器

| 浏览器 | 最低版本 | 标签页捕获方式 | 备注 |
|--------|---------|---------------|------|
| Chrome | 88+ | tabCapture（自动） | 无缝捕获，无需手动选择 |
| Edge | 88+ | tabCapture（自动） | 无缝捕获，无需手动选择 |
| Firefox | 112+ | getDisplayMedia（手动） | 需在弹窗中选择标签页并勾选"分享音频" |

## 安装方法

### Chrome / Edge

1. 下载并解压本扩展文件夹。
2. 打开浏览器扩展管理页面（`chrome://extensions` 或 `edge://extensions`）。
3. 开启"开发者模式"。
4. 点击"加载已解压的扩展程序"，选择解压后的文件夹。

### Firefox

1. 打开 `about:debugging#/runtime/this-firefox`。
2. 点击"临时加载附加组件"。
3. 选择本文件夹中的 `manifest.json` 文件。

> 注意：Firefox 目前仅支持临时加载未签名的扩展。如需永久安装，需要通过 [addons.mozilla.org](https://addons.mozilla.org) 签名发布。

## 使用方法

1. 打开正在播放英语听力音频或视频的普通网页。
2. 点击扩展图标，再点击"打开录音窗口"。
3. （Firefox）在弹出的共享选择器中选择当前标签页，并勾选"分享标签页音频"。
4. 点击"开始录制"。
5. 录制完成后，拖动波形上的左右黄色把手选择片段，也可以拖动黄色选区整体移动。
6. 点击"试听片段"确认内容，再选择格式并点击"保存片段"下载。

### 固定窗口置顶

- 点击录音窗口右上角的 **📌 图钉按钮**，窗口将固定在浏览器最前面。
- 再次点击取消固定。
- 实现原理：监听窗口焦点变化事件，当其他窗口获得焦点时自动将录音窗口重新聚焦。

### 波形优化说明

- **频率多样化**：每个音频块分成 4 个子块独立记录 min/max/RMS，数据量提升 4 倍，有效解决波形频率单一的问题。
- **渐变色波形**：从浅珊瑚 → 橙红 → 深红的垂直渐变，层次分明。
- **不对称波形条**：上下分别使用 max/min 值，更接近真实音频特征。
- **紧凑面积**：波形画布高度从 190px 缩小到 120px，减少空间占用。

## 文件结构

```
├── manifest.json       — 扩展清单（权限、入口、浏览器兼容配置）
├── background.js       — 后台 Service Worker（消息处理、tabCapture 流 ID 获取）
├── popup.html / .css   — 扩展弹窗界面
├── popup.js            — 弹窗逻辑（获取当前标签页、打开录音窗口）
├── recorder.html       — 录音窗口界面（含固定窗口按钮）
├── recorder.css        — 录音窗口样式（固定按钮、波形面板美化）
├── recorder.js         — 录音核心逻辑（捕获、录制、波形绘制、导出、固定窗口）
└── README.md           — 本文件
```

## 注意事项

- `chrome://`、`edge://`、`about:` 等浏览器内部页面不能被录制。
- 录制时请保持录音窗口打开。
- 长录音会暂存在内存中，保存或关闭窗口前不会写入文件。
- 当前版本支持保存 WAV 和 WEBM；MP3 会尝试使用浏览器原生编码，如果浏览器不支持，会提示先保存 WAV 或 WEBM。
- 如果 B 站等视频网页没有录到声音，请确认是从目标视频页点击扩展图标打开录音窗口，并在视频开始播放后再点"开始录制"。
- 请确认你有权保存所录制的媒体内容。
